# 03 数据与标注

## 1. 语料（corpus）

**用什么**：你自己的操作系统笔记 / 教材章节整理稿 / 课程 PPT 转成的 md。每篇 800–3000 字，**一篇对应一个章节**（便于按章节分析失败案例）。

**不要**：直接把整本 PDF 丢进去。页眉、页码、公式乱码会严重污染检索，而且你没法解释"为什么这段是垃圾"。

**格式**：`data/corpus/<章节>.md`，纯文本，段落之间空一行（切分器按空行识别段落）。

**版权**：教材原文只在本机使用，`data/corpus/` 加进 `.gitignore`；公开仓库只放你**自己写的**笔记摘要和标注文件。

## 2. Query 集（200 条）

来源：408 历年真题（2009–2024）操作系统部分。

**改写规则**（很重要，决定实验是否公平）：
1. 去掉选项 A/B/C/D，只留题干。
2. 去掉"下列说法正确的是"这类无信息量前缀。
3. 保留术语原文（"页表""TLB""时间片"），不要改写成口语——否则你测的是改写能力，不是检索能力。
4. 大题拆成可检索的小问。

**为什么不直接用教材课后题**：真题有标准答案，且分布真实；课后题和教材正文措辞太像，会导致 recall 虚高。

## 3. Gold 段落标注

对每条 query，在语料里标 1–3 个"能回答这个问题"的段落。

- 标 **para 序号**（从 0 开始，按空行分隔的顺序），不标字符位置——这样换 chunk 大小不影响标注。
- 标注时间预算：**每题 30 秒**，200 题 ≈ 100 分钟，分两次做完。
- 判断题："如果只给读者这一段，他能答出这题吗？"能 → 标；不能 → 不标。
- 允许标 2–3 段（答案分散时），这样 recall 才有区分度。

**一致性抽检**：隔一天，随机抽 20 条重标，算"两次标注的重合率"。≥85% 就写进实验记录；低于就说明标准不清，先统一标准再继续。

## 4. 数据格式

`data/queries.jsonl`，一行一条：

```json
{"qid":"q001","query":"进程和线程的区别是什么","gold":[{"doc":"os-03","para":7}],"type":"概念","year":2016}
```

字段说明：
- `qid`：唯一 id，别改（结果 CSV 用它对齐）
- `query`：检索用的文本
- `gold`：段落列表，`doc` 是 `data/corpus/xxx.md` 的文件名（不含扩展名）
- `type`：概念 / 计算 / 综合，用于分层分析
- `year`：真题年份（可选，用于"新题是否更难"的分析）

## 5. 示例数据

语料 `data/corpus/os-01.md … os-36.md` 共 36 篇、约 6.8 万字、306 段，按 408 大纲分章撰写（每篇 1 700–2 000 字、7–10 段，段间空一行）。

第 16–18 篇是补 gold 缺口时新增的：os-16 进程通信与并发执行（管道、消息传递、共享存储、指令交错计数）、os-17 调度进阶（优先级设置依据、动态优先数、多级反馈队列与多道 I/O 重叠算例）、os-18 存储层次（Cache/TLB 组相联、地址位划分、LRU 置换）。另有 4 段补在 os-01（批处理系统）、os-09（空闲页框链扫描回收）、os-11（权限位串位数）、os-12（簇分配取整）末尾。

第 19–36 篇是压"语料太小导致 recall 天花板"时新增的 18 篇，全部写**新内容**（算例变体 / 易错辨析 / 多步推导），不复述已有段落：os-19 状态与上下文切换、os-20 线程实现与多线程模型、os-21 五种调度算法同作业集对比、os-22 三个经典同步问题完整 PV、os-23 信号量与管程易错点、os-24 死锁检测与银行家多算例、os-25 连续分配四算法同序列、os-26 分页/分段/段页式地址计算对比、os-27 多级页表级数推导、os-28 五种置换算法同引用串 + Belady、os-29 工作集与抖动、os-30 目录与索引结点容量正反算、os-31 文件分配与空闲空间、os-32 六种磁盘调度同序列、os-33 磁盘性能与 RAID、os-34 四种 I/O 控制方式 CPU 开销、os-35 设备分配/SPOOLing/缓冲、os-36 三条全链路串讲。

旧的 `os-001.md`、`os-002.md` 两篇示例语料在正式语料到位后已删除。

判断语料是否合格（含 13-gram Jaccard ≥ 0.5 的近似重复检测）：

```
py -3 src\check_corpus.py --min-files 36
```

它查字数区间、段数、段长、Markdown 残留、禁用语、跨文件重复段落、近似重复对，并打印每篇的字数与段数。

## 6. 常见坑

| 坑 | 现象 | 解法 |
|---|---|---|
| gold 标在 chunk 上 | 换 size 后 recall 全乱 | 一律标段落 |
| 一问多答只标一段 | recall 天花板只有 0.5 | 标全 1–3 段 |
| 语料有重复段 | recall 虚高 | 建索引前去重（按段落 hash） |
| query 含选项 | 检索被 "A." "B." 干扰 | 去掉选项 |
| 页眉混入 | 每篇开头都有"第 3 章 内存管理" | 清洗时删掉重复行 |
