# 07 本地环境（全本地跑 dense / rerank）

> 结论先行：**你这台机器（RTX 4050 6G + 16G 内存 + D 盘 144G 空闲）完全够，不用买 API。**
> 但要认清代价：第一次装环境 1–2 小时，之后每次换 chunk 大小都要重算 embedding。
>
> **2026-11-08 已装好并验证**：torch 2.15.0+cpu / sentence-transformers 6.2.0 / transformers 5.22.2 / numpy 2.5.4，
> 模型 bge-small-zh-v1.5（**512 维**，不是文档原先写的 384）。`check_local_env.py` 通过，64 条文本编码 0.14s。

## 1. 你机器上的实测现状

| 项 | 现状 | 结论 |
|---|---|---|
| Windows Python | 3.13.9（`py -3`，自带 pip 25.2）；`python` 是 Store 空壳，别用 | 可直接建 venv |
| WSL Python | **没装**（`python3: command not found`） | 要用就得先 `sudo apt install python3 python3-pip python3-venv`，需要你的 sudo 密码 |
| GPU | NVIDIA RTX 4050 Laptop（6G） | 可选加速；bge-small 用 CPU 就够 |
| 磁盘 | C: 110G / D: 144G 空闲 | 装 CUDA 版 torch（约 3.5G）也无压力 |
| 内存 | WSL 分配 7G，主机 16G | 够；batch 别开太大 |

## 2. 需要装什么

| 组件 | 体积 | 为什么 |
|---|---|---|
| torch（**CPU 版**） | 126 MB（2.15.0+cpu） | 够了，bge-small 只有 2400 万参数 |
| sentence-transformers | ~50MB | embedding + cross-encoder 的统一封装 |
| bge-small-zh-v1.5 | 95MB | 中文小模型，**512 维**，CPU 也可用 |
| bge-reranker-base（可选） | 1.1GB | 只有做 Q3（rerank 值不值）才需要 |

想用 GPU 加速：把 torch 换成 CUDA 版（`cu124`，下载约 2.5G），其余不变。**不要一上来就装 CUDA 版**，先跑通 CPU。

## 3. 安装步骤（Windows，推荐）

```powershell
cd <项目根目录>   # 例：cd "D:\code\408-rag-eval"

# 1) 建独立环境（用 py -3；机器上的 python 是 Store 空壳，别用）
py -3 -m venv .venv

# 之后一律用这个绝对路径，不必每次 activate
.\.venv\Scripts\python.exe -V

# 2) torch 走官方 CPU 索引，但**别直接 pip install**（见 §7 第 1 条）
curl.exe -L -C - --retry 20 --speed-limit 20480 --speed-time 15 `
  -o <临时目录>\torch-2.15.0+cpu-cp313-cp313-win_amd64.whl `
  "https://download.pytorch.org/whl/cpu/torch-2.15.0%2Bcpu-cp313-cp313-win_amd64.whl"

# 3) 装本地 wheel + 其余依赖，PyPI 用阿里云镜像（清华会 403）
.\.venv\Scripts\python.exe -m pip install "<临时目录>\torch-2.15.0+cpu-cp313-cp313-win_amd64.whl" `
  -i https://mirrors.aliyun.com/pypi/simple/ --trusted-host mirrors.aliyun.com

.\.venv\Scripts\python.exe -m pip install sentence-transformers `
  -i https://mirrors.aliyun.com/pypi/simple/ --trusted-host mirrors.aliyun.com

# 4) 模型走镜像（HuggingFace 直连大概率超时）
$env:HF_ENDPOINT = "https://hf-mirror.com"

# 5) 验证
.\.venv\Scripts\python.exe src\check_local_env.py
```

第一次运行 `check_local_env.py` 会自动下载 95MB 模型（耗时约 1 分钟），之后完全离线。
之后跑 dense 评测：

```powershell
.\.venv\Scripts\python.exe src\dense_eval.py --size 512 --overlap 0 --out results\dense_512_0.csv
```

## 4. 候选方案对比

| 方案 | 优点 | 缺点 | 建议 |
|---|---|---|---|
| Windows venv + CPU torch | 最省事，不碰 sudo | reranker 慢 | **首选** |
| Windows venv + CUDA torch | reranker 快 5–10× | 下载 2.5G，显存占用 | 做 Q3 再换 |
| WSL + apt 装 python | 和 Linux 生态一致 | 要 sudo 密码，装两遍 | 不必要 |
| API（bge-m3 等） | 最强 | 花钱、要网络、要缓存 | 3 周版不做 |

## 5. 全本地跑的缺点（诚实版）

1. **第一次装环境很痛**。torch 大、pip 源慢、HF 被墙，这三个坑任何一个都能耗掉一晚上。对策：按上面 4 步走，不要自己另找教程。
2. **换 chunk 大小就要重算 embedding**。这是最大的时间成本：`size` 有 4 档，就等于把 3000 个 chunk 编码 4 遍。对策：3 周版**只对 2 档（256 / 512）跑 dense**，其余档位只跑 BM25。
3. **CPU 上 reranker 很慢**。200 题 × top-20 候选 = 4000 次 cross-encoder 前向，CPU 约 3–8 分钟/组；有 4050 的话 30 秒内。对策：rerank 只跑 2 组配置（开/关），别放进网格。
4. **小模型精度有限**。bge-small 在术语密集的短 query 上**未必赢 BM25**。这不是失败，是结论——"在 408 语料上，小模型 dense 不如 BM25"本身就能讲，而且比"我用了向量库"有价值。
5. **延迟数字失去产品意义**。CPU 上的 P95 延迟反映的是你的电脑，不是系统性能。报告里要写清楚："延迟为单机 CPU 测量值，仅用于**配置间相对比较**"。
6. **可复现性依赖版本**。模型版本、torch 版本写进 README，否则半年后本机也跑不出同样结果。

## 6. 3 周版里 dense 的正确用法

不要放进网格，只做**两个单点对比**：

| 配置 | 用途 |
|---|---|
| BM25, 最优 size（网格选出） | 基线 |
| bge-small, 同一 size | "向量检索到底强多少" |
| 可选：bge-small + rerank | 只在时间富余时做 |

这样 dense 只编码 **1–2 次**，总耗时控制在 20 分钟以内。

## 7. 排错

| 现象 | 原因 | 解法 |
|---|---|---|
| `pip install torch` 卡在 45MB 左右不动 | 官方索引的单连接被限速/断流（实测先 2.3MB/s、几十秒后停滞） | **先 `curl -C -` 断点续传到本地，再 `pip install 本地.whl`**；文件名必须保持 `torch-2.15.0+cpu-cp313-cp313-win_amd64.whl` 原样，改名成 `torch_cpu.whl` 会报 `Invalid wheel filename` |
| 清华源报 `403 Client Error: Forbidden` | 清华 PyPI 镜像对部分 wheel 直链拒绝 | 换 `-i https://mirrors.aliyun.com/pypi/simple/ --trusted-host mirrors.aliyun.com` |
| `pip install torch` 卡住/几个 G | 装成了 CUDA 版 | 用 `--index-url .../whl/cpu` 或上面的本地 wheel |
| 下载模型 timeout | HF 直连被墙 | `$env:HF_ENDPOINT = "https://hf-mirror.com"` |
| `OSError: [WinError 126]` | torch 与 numpy 版本冲突 | 先 `pip install "numpy<2"` 再装 torch |
| `Invalid wheel filename (wrong number of parts)` | 把 wheel 改成了不含版本/平台的短名 | 保持原始文件名 |
| 显存不足 | batch 太大 | `batch_size=8`，或改 CPU |
| 编码速度极慢 | 没开多线程 / 用了 `transformers` 原生接口 | 用 sentence-transformers 的 `encode(batch_size=32)` |
