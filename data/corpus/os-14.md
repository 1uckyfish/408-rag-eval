I/O 设备按数据组织方式分为块设备和字符设备。块设备以固定大小的数据块为单位存取，如磁盘、固态盘，支持随机访问和寻址；字符设备以字符流为单位顺序存取，如键盘、打印机、串口，不可寻址，多采用中断方式驱动。按资源分配特性分为独占设备、共享设备和虚拟设备，独占设备在一段时间内只允许一个进程使用；共享设备可被多个进程交替使用。按传输速率还可分为低速和高速设备，键盘属低速。

I/O 接口又称设备控制器，是 CPU 与设备之间的中介，负责接收命令、控制设备动作并报告状态。它通常包含数据寄存器、状态寄存器和控制寄存器。数据寄存器暂存 CPU 与设备之间传送的数据，起缓冲作用；状态寄存器保存设备的工作状态，如忙、就绪、出错，供 CPU 查询或作为中断源；控制寄存器存放 CPU 下发的命令字，如启动、读、写。控制器内部还有地址译码电路，用于识别选中的设备。

CPU 访问控制器中的寄存器需要为它们分配地址，常见方式有独立编址和内存映射编址。独立编址为 I/O 端口单独开辟地址空间，使用专门的 I/O 指令访问，优点是 I/O 地址不与内存地址冲突，缺点是必须使用专用指令。内存映射编址把设备寄存器映射到内存地址空间，用普通访存指令即可读写，编程方便，但会占用内存地址空间，且难以区分访存与 I/O 操作。

程序查询方式又称轮询方式。CPU 启动设备后不断读取状态寄存器，检查设备是否就绪，就绪后由 CPU 执行数据传送指令，把数据从控制器的数据寄存器搬到内存。设备未就绪时 CPU 反复测试状态位，形成忙等待，不能做其他工作，因此 CPU 与设备串行工作，时间大量浪费在查询上。该方式结构简单，不需要中断机构，适合设备速度较快或 CPU 无其他任务的场合。

中断驱动方式下，CPU 启动设备后转去执行其他程序，设备完成一个字的传送后向 CPU 发出中断请求，CPU 响应中断并执行中断处理程序，把数据取走、再次启动设备，然后返回断点。这样 CPU 与设备可以并行工作，不必空等。但每传送一个字都要经历一次中断，中断响应、保存现场和恢复现场的开销很大，设备多或数据量大时中断次数过多，会严重占用 CPU。该方式适合低速字符设备。

DMA 方式在控制器中增加 DMA 控制器，由它直接控制内存与设备之间的数据传送，一次传送一个数据块。CPU 只需在传送开始前设置内存起始地址、传送长度和传送方向，然后启动 DMA；DMA 控制器接管总线，逐字完成整个数据块的搬运，全部结束后才向 CPU 发一次中断。因此 CPU 的干预频率降到每块一次。DMA 控制器与 CPU 共享总线，需要总线仲裁，常用周期挪用法窃取总线周期。

通道是一种专门负责 I/O 的处理器，能执行通道程序。CPU 向通道发出一条启动 I/O 指令并给出通道程序的首地址，通道便独立地从内存取出通道指令，控制设备完成一组数据块的传送，过程中不需要 CPU 干预，全部完成后通过中断向 CPU 报告。通道进一步把 CPU 从繁琐的 I/O 控制中解放出来，干预频率降到每组数据块一次。按信息交换方式，通道分为字节多路、数组选择和数组多路三种。

四种控制方式的差别体现在数据传送单位和 CPU 干预频率上。程序查询方式以字为单位，CPU 全程参与，干预最频繁；中断方式也以字为单位，CPU 在传送间隙可执行其他程序；DMA 方式以数据块为单位，每块只在开始和结束时干预两次；通道方式以一组数据块为单位，每组的开始和结束各干预一次。从查询到中断再到 DMA 和通道，CPU 干预频率依次降低，硬件复杂度和成本依次升高，并行程度依次提高。

缓冲技术用于缓和 CPU 与设备速度不匹配的矛盾，减少中断次数，提高并行性。单缓冲在设备与处理机之间设置一个缓冲区，设备向缓冲区输入数据与 CPU 从缓冲区取走数据不能同时进行；双缓冲设置两个缓冲区，可做到一块输入的同时另一块被处理；循环缓冲由多个大小相等的缓冲区构成环形队列，适合速率波动较大的场合；缓冲池把多个缓冲区集中管理，按需分配，可供多个进程共享，利用率最高。

设设备读入一块数据的时间为 100 微秒，数据传送到用户区的时间为 5 微秒，CPU 分析一块的时间为 90 微秒。单缓冲下处理第一块需读入、传送、分析共 195 微秒，此后每块的时间为最大值(读入时间, 分析时间) 加传送时间，即 105 微秒，故处理 n 块的总时间为 195 加 105 乘以 (n 减 1)，读完并分析 2 块为 300 微秒。双缓冲下每块的时间为最大值(读入时间, 传送时间加分析时间)，即 100 微秒。
