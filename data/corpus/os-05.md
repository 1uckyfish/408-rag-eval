临界资源是一次仅允许一个进程使用的资源，如打印机和共享变量；进程中访问临界资源的那段代码称为临界区。互斥指多个进程争用同一临界资源时须排他地进入临界区，解决谁先用的问题；同步指协作进程之间须按约定的先后次序执行，解决谁先做的问题，互斥可以看作同步的特例。实现临界区互斥须遵循四条准则：空闲让进、忙则等待、有限等待和让权等待。

单标志法设 turn 表示当前允许进入的进程，退出时让给对方，两进程只能交替进入，违背空闲让进。双标志先检查法为每个进程设标志，进入前先查对方标志再置自己的标志，两步之间可能发生切换，双方都看到对方未进入而同时进入，违背忙则等待。双标志后检查法先置标志再检查，虽避免同时进入，但双方同时置标志后互相谦让，谁也无法进入，违背空闲让进并可能饥饿。

Peterson 算法为每个进程设置一个标志，进入前先把 turn 让给对方，再检查对方标志与 turn，只有当对方不想进入或 turn 指向自己时才进入，因而两个进程不会同时进入临界区，退出时把自己的标志置为假。该算法满足空闲让进、忙则等待和有限等待，但只能用于两个进程，且未进入的进程在循环中测试，属于忙等，不满足让权等待。

硬件方法依靠机器指令保证互斥。中断屏蔽在进入临界区前关中断、退出后开中断，简单有效，但期间系统无法响应中断，只适合单处理机，也不允许用户程序随意使用。TestAndSet 指令原子地读出标志旧值并置为真，返回真表示已被占用；Swap 指令原子地交换两个变量的值。两者都能在多处理机上工作，但未获得锁的进程一直循环测试，处于忙等，不满足让权等待。

信号量是一个整型变量，除初始化外只能由 P、V 两个原语访问。P 操作把信号量减 1，若结果小于 0 则调用进程阻塞并插入等待队列；V 操作把信号量加 1，若结果小于等于 0 则从等待队列唤醒一个进程。值大于 0 时表示尚可用的资源数目，等于 0 表示资源恰好用完且无进程等待，小于 0 时其绝对值等于在该信号量上等待的进程数。例如值为 -2，表示资源已耗尽且有两个进程正在等待。

用信号量实现互斥的模板是：为临界资源设初值为 1 的互斥信号量，进入临界区前执行 P，退出后执行 V。实现同步的模板是：为前驱关系设初值为 0 的信号量，前驱进程在操作后执行 V，后继进程在操作前执行 P。生产者与消费者问题中，empty 表示空闲缓冲区数，初值为缓冲区总数；full 表示已有产品数，初值为 0；mutex 用于互斥访问缓冲区，初值为 1。

缓冲区共 n 个并组织成环形，in 与 out 分别为写、读位置。生产者：P(empty)、P(mutex)、放入 buffer[in]、in =（in + 1）% n、V(mutex)、V(full)。消费者：P(full)、P(mutex)、取出 buffer[out]、out =（out + 1）% n、V(mutex)、V(empty)。两个 P 的顺序不能颠倒：若生产者先 P(mutex) 再 P(empty)，缓冲区满时占着锁等空位，消费者拿不到 mutex 无法取产品，互相等待形成死锁。

读者与写者问题中，多个读者可同时读，写者与任何进程互斥。读优先方案设 count 记录读者数、mutex 保护 count、rw 实现读写互斥：读者进入前 P(mutex)，count 加 1，若为 1 则 P(rw)，再 V(mutex) 开始读；退出时 P(mutex)，count 减 1，若为 0 则 V(rw)，再 V(mutex)。只要还有读者在读，写者就被阻塞，写者可能饥饿。写优先方案再加一个信号量，让后续读者在写者到达后等待。

哲学家进餐问题中，五位哲学家围坐，每两人之间放一只筷子，哲学家交替思考和进餐，进餐须同时拿起左右两只筷子。若每人都先拿左边再等右边，五人各持一只并循环等待，形成死锁。解决思路有三：限制至多四人同时拿筷子；要求一次拿起两只筷子，把取筷动作放在临界区内原子完成；规定奇数号先拿左边、偶数号先拿右边，破坏循环等待条件。

理发师问题中，理发师与顾客构成生产者与消费者关系，但座位有限。设座位数为 N，customers 表示等待的顾客数，初值为 0；barber 表示理发师是否空闲，初值为 0；mutex 保护等待人数，初值为 1。顾客到来时执行 P(mutex)，若等待人数小于 N 则人数加 1、V(customers)、V(mutex)，再 P(barber) 接受服务，否则 V(mutex) 后离开。理发师执行 P(customers)、V(barber) 后服务。
